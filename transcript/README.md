# Chat transcripts

The source transcript is not available in this checkout yet. Export the Codex conversation and place the PDF or Markdown export in this directory before submitting.

The assignment asks for the exported chat transcript of the AI-assisted work. Put the exports here:

| File | What it is |
|---|---|
| `claude_cowork_transcript.pdf` (or `.md`) | Full agentic-coding session that planned, wrote, audited and fixed this repository |
| `chatgpt_transcript.pdf` *(optional)* | If you also ran the professor's prompt in ChatGPT (e.g. with the SaveGPT extension) |

**How to export:**
- **Claude:** open the conversation, then use the share/export option, or print the page to PDF (Cmd+P → Save as PDF).
- **ChatGPT:** use the *SaveGPT* / *ChatGPT to PDF* browser extension, or Settings → Data controls → Export.
